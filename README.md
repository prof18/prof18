## Ciao, I'm Marco 👋

I build apps and the agent tooling that builds them.

Principal Android Engineer at [Airalo](https://www.airalo.com) · Google Developer Expert for Android · Berlin

I build mobile apps, desktop apps, CLIs, and whatever else a problem needs. Lately most of my time goes into the agent side: skills, subagents and workflows that take a change from discussion to a merged pull request.

### 📱 Apps

- [**FeedFlow**](https://feedflow.dev) — minimal RSS reader with cross-device sync and a reader mode. Android, iOS, macOS, Windows, Linux.
- [**ReaderFlow**](https://readerflow.app) — privacy-focused read-it-later app that works offline.
- [**Difftray Mobile**](https://difftray.app) — companion to Difftray: pair with your Mac and review changes from your phone or tablet, with no cloud backend.
- [**PomoStats**](https://pomostats.app) — unofficial App Store Connect client for Android.
- [**CueUp**](https://cueup.cc) — video presentations: the video on the projector, the controls on your screen.
- [**Slashgrab**](https://slashgrab.app) and [**Shellporter**](https://shellporter.com) — small macOS menu bar utilities.

### 🤖 Agent tooling

- [**mgkit**](https://github.com/prof18/mgkit) — my workflow for building with agents: roast, plan, execute, review, ship.
- [**Difftray**](https://difftray.app) — local-first macOS app for reviewing Git changes across projects. Tracks what you reviewed, flags drift, and turns your review notes into prompts for your agent.
- [**regesto**](https://github.com/prof18/regesto) — a plain-markdown knowledge base that agents read before they act.
- [**claudup**](https://github.com/prof18/claudup) — keeps one Claude Code Remote Control bridge running per project on an always-on Mac, so every project is its own environment in the Claude app.

### 🚀 Shipping tooling

- [**pcenter**](https://github.com/prof18/pcenter-cli) — publish and manage Microsoft Store releases from the command line.

### 📚 Libraries

- [**RSS-Parser**](https://github.com/prof18/RSS-Parser) — Kotlin Multiplatform parser for RSS, Atom and RDF feeds.
- [**klead**](https://github.com/prof18/klead) — Kotlin Multiplatform library that extracts clean article content from web pages.

### 🧩 Obsidian plugins

- [**Bases Kanban Toolbox**](https://github.com/prof18/bases-kanban-toolbox) — improves Obsidian's native Bases Kanban boards: manual card order, compact cards, collapsible columns and a card popup.
- [**HTML Shelf**](https://github.com/prof18/html-shelf) — browse and read the HTML files in your vault, on mobile and desktop, without leaving Obsidian.
